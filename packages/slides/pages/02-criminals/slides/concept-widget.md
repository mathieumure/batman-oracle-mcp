::title::
C'est quoi une UI MCP ?

::default::
Un tool peut porter un **widget** : une app qui s'affiche dans l'hôte, à côté de la conversation.

Le widget est branché sur une **resource** ; le tool y ajoute une **meta** pour dire quoi afficher.
